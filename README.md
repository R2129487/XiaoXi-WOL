# 小希 WiFi WOL 远程启动棒

**小希（XiaoXi）** — 插上网口，就能远程开机。

一个基于 ESP32 + LAN8720 的 WiFi 远程网络唤醒（Wake-on-LAN）硬件项目。

---

## 概述

**小希**是一个即插即用的硬件小工具：
- **形态**：U盘大小，一头USB取电，一头RJ45插电脑网口
- **功能**：通过WiFi接收指令，发送WOL魔术包远程开机
- **目标**：不用拆机，不用接线，笔记本台式机通用

## 项目结构

```
xiaoxi-wol/
├── firmware/           # ESP32固件源码
│   ├── main/           # 主程序
│   ├── web/            # Web管理页面
│   └── mqtt/           # MQTT客户端
├── hardware/           # 硬件设计
│   ├── pcb/            # PCB设计文件（立创EDA）
│   └── enclosure/      # 3D打印外壳文件
├── docs/               # 文档
│   └── guide.md        # 配网指南
├── server/             # 云端服务（Hermes对接）
└── 方案书.md            # 项目方案书
```

## 控制方式

| 层级 | 方式 | 说明 |
|:--:|:--|:--|
| 🥉 | 本地Web | 启动棒自带网页，手机浏览器直接控制 |
| 🥈 | MQTT云端 | 对接MQTT，异地远程、定时任务 |
| 🥇 | Hermes | 对接GTS团队Hermes系统，动动嘴开机 |

## 供电方案

- **主方案**：USB取电（插电脑USB口）
- **备用方案**：Type-C独立供电（插手机充电头）
